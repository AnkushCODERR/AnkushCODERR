## Selected Projects & Research

### 1. ScureLocalAI
**Privacy-Preserving Local Multimodal RAG Assistant**

Developing a local AI assistant focused on privacy-preserving document understanding, multimodal retrieval and locally executed LLM workflows.

**Focus:** RAG, LLMs, document intelligence, multimodal retrieval and local inference.

### 2. MMClueEdu
**Multimodal Clue-Based Learning Dataset for Educational Videos**

A dataset automation and processing project involving educational video understanding through synchronized audio, visual and textual information.

**Focus:** Video processing, speech transcription, OCR, keyframe extraction and multimodal synchronization.

### 3. Smart Depth Vision
**Visual Cue-Based Learning in a Multimodal Learning Environment**

An experimental computer vision project exploring depth-aware visual understanding and classification using RGB and depth-related visual cues.

**Focus:** Computer Vision, YOLO, MiDaS, ResNet and multimodal learning.

### 4. Agentic AI-Based Digital Twin Framework
**Multi-Hazard Weather Prediction**

Research-oriented work exploring agentic AI and digital twin concepts for multi-hazard weather prediction.

**Focus:** Agentic AI, intelligent systems and predictive modelling.
